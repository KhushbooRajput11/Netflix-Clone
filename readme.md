
# 🎬 Netflix Clone

A Netflix-inspired website built using HTML, CSS, and JavaScript. This project recreates the look and feel of a streaming platform as a frontend development project.

## 📌 About the Project

The Netflix Clone is a web development project created to practice frontend development skills, including webpage layout, styling, and responsive design.

## ✨ Features

- Netflix-inspired user interface
- Dark theme and modern layout
- Movie and TV show sections
- Responsive design (if implemented)
- Interactive elements (if implemented)
